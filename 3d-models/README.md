
# Vayu Astra — 3D Prototype Models

## Overview

This directory is intended for the
latest Vayu Astra prototype models,
design iterations, and assembly references.

## Prototype Design

The current design incorporates:

- Raspberry Pi Camera Module 3
- Raspberry Pi computer
- ESP32 controller
- MG996R pan and tilt servos
- Camera mounting bracket
- PCA9685 servo driver
- Power distribution board
- Laser pointer
- Buzzer
- Power switch
- Mounting platform

## Planned Thermal Sensor

Status: DESIGN STAGE — NOT INSTALLED

The updated 3D design places the
thermal sensor outside the camera
U-bracket, near the camera assembly.

This placement is intended to support
future thermal and visual sensing
experiments.

Physical installation and sensor
alignment have not yet been verified.

## Design Priorities

- Clear spacing between components
- Accessible power connections
- Organized wiring paths
- Protection against cable twisting
- Restricted servo movement
- Secure sensor mounting
- Clear component identification

## Model Versions

Existing 3D models should be retained
until the latest version has been
uploaded and reviewed.

Future model files can be stored here
with descriptive versioned filenames.

## Important Note

A 3D visualization illustrates the
proposed arrangement.

It does not independently verify
electrical connections, mechanical
clearances, or operational performance.
