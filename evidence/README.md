
# Vayu Astra — Prototype Evidence

## Overview

This directory documents the physical
Vayu Astra prototype and its development.

Evidence is organized separately from
AI-generated concept visualizations.

## Physical Prototype

Vayu Astra is an evolving physical
prototype using:

- Raspberry Pi
- Raspberry Pi Camera Module 3
- ESP32
- MG996R pan/tilt servos
- Camera mounting assembly
- Supporting electronic components

## Evidence Categories

### Hardware Photographs

Actual photographs of the assembled
prototype and its components.

### Software Demonstrations

Screenshots or recordings of software
running on the physical hardware.

### Testing Results

Measured observations, test conditions,
and verified experimental outcomes.

## Evidence Guidelines

- Use authentic prototype photographs.
- Identify the date and version when known.
- Do not present AI-generated images as real.
- Do not claim untested features are working.
- Preserve original evidence files.
