
# Vayu Astra — Hackathon & Demonstration History

## Overview

Vayu Astra is an evolving AI-assisted
surveillance and object-tracking prototype.

This directory organizes hackathon
submissions, technical presentations,
demonstration evidence, and project
development milestones.

## Project Development

The prototype has evolved through
multiple hardware and software iterations.

Each event may use a different version
of the design, depending on the features
implemented and tested at that time.

## Recommended Record Structure

Each event can have its own folder
containing:

- README.md — Event and submission details
- presentation.pdf — Submitted presentation
- demo/ — Demonstration materials
- results.md — Confirmed outcomes
- prototype-version.md — Features at submission

## Prototype Versioning

Earlier submissions should remain
preserved even when the current
prototype receives new features.

For each submission, record:

1. Submission date
2. Prototype version
3. Implemented functionality
4. Planned functionality
5. Demonstration evidence
6. Verified event outcome
