
# Vayu Astra — Smart India Hackathon 2026

## Project Information

**Team:** Vayu Astra

**Event:** Smart India Hackathon 2026

**Problem Statement ID:** SIH26050

**Project:** High-Altitude Performance Optimization and Robust Design of an Anti-Drone System

**Theme:** Defence & Strategic Technologies

## Problem Overview

Monitoring and tracking aerial objects in
challenging environments requires reliable
sensing, processing, and mechanical control.

Vayu Astra explores an AI-assisted
surveillance architecture using computer
vision and an embedded pan/tilt mechanism.

## Proposed Solution

The project investigates a modular system
combining:

- Camera-based visual sensing
- Raspberry Pi edge processing
- OpenCV image processing
- ESP32-based control
- MG996R pan/tilt servos
- Browser-based camera monitoring
- Future thermal sensing integration

The long-term objective is to improve
observation and tracking capabilities
through multi-sensor integration.

## Prototype Development

Vayu Astra has a working physical prototype
and is undergoing further integration
and testing.

The repository includes reference software,
hardware documentation, and an interactive
3D design.

Uploaded reference software should not
be interpreted as verified end-to-end
performance evidence.
